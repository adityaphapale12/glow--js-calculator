# ✨ Glow JS Calculator

A simple and stylish calculator built using **HTML, CSS, and JavaScript** with a glowing UI effect.

---

## 📌 Features

- Basic arithmetic operations (+, -, ×, ÷)
- Clean and modern glowing interface
- Responsive design for mobile and desktop
- Fast and lightweight (no frameworks used)
- Smooth button interactions

---

## 🛠️ Technologies Used

- HTML5 – Structure of the calculator  
- CSS3 – Styling and glow effects  
- JavaScript – Functionality and logic
